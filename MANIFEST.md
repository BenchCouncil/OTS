# Release Manifest

## Chapter 2: Closed-World Time-Series Forecasting

- `chapter_2_closed_world/code/shallow_baselines/`: shallow OLS-family baselines and scripts.
- `chapter_2_closed_world/code/deep_models/`: Time-Series-Library based deep models and reversal-grid scripts.
- `chapter_2_closed_world/code/analysis/`: parsing and statistical testing scripts.
- `chapter_2_closed_world/code/paper_tables/`: table-generation scripts.
- `chapter_2_closed_world/results/local_tables_and_metrics/`: local CSV/JSON/XLSX result summaries.
- `chapter_2_closed_world/results/reversal_analysis_tables/`: parsed deep-model result tables.
- `chapter_2_closed_world/results/partial_channel_results_20260718/`: extracted partial-channel metrics and masks.
- `chapter_2_closed_world/results/server_archives/`: raw compressed server outputs and checksums.
- `chapter_2_closed_world/results/paper_table_inputs/`: table inputs and generated LaTeX table outputs.
